how it's protected

  1. no secrets in your browser. the api key lives in a cloudflare server-side function. view source all you like.
  2. scoped, rate-limited key. it can only reach one model, with limits set at the gateway.
  3. input limits. 500 characters a message, and the server trims the history.
  4. system prompt stays server-side. you can't replace its instructions.
  5. red-teamed with prompt injection from my kali box.
  6. monitored. gateway and host logs go to wazuh.
  7. strict headers. csp, hsts, zero trackers.

it lives on my pc, so if it's offline my computer is off. you'll get pre-written answers instead.
